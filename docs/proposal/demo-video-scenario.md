# AUTONOMICS 시연 영상 시나리오

완성본: `demo-video/AUTONOMICS_demo.mp4` · 다시 만들기: `python3 docs/proposal/demo-video/build_video.py` (원본은 `demo-video/raw/`, 자막은 `demo-video/overlays/`)

기획서 06쪽의 네 단계(출발 전 → 주행 중 → 중간 하차 → 도착)를 그대로 따르고, 뒤에 "차라서 되는 것" 세 가지를 짧게 붙인다.

## 1. 형식

| 항목 | 정한 값 | 이유 |
|---|---|---|
| 길이 | 2분 16초 (완성본) | 공식 제한은 없다. 심사위원이 끝까지 볼 길이로 잡았다 |
| 화면 | 1920×1080, 에뮬레이터 전체 화면(왼쪽 계기판 + 오른쪽 앱) | 계기판 속도와 앱 반응이 한 화면에 보여야 "차량 데이터로 움직인다"가 증명된다 |
| 소리 | 자막만 (무음, 내레이션·배경음 없음) | 소리를 끄고 봐도 전부 이해돼야 한다. 음성 입력 장면은 무엇을 말했는지 글자로 표시한다 |
| 자막 | 장면마다 한 줄(20자 안팎) + 쓰인 SDK 표시 | 기술 활용성을 장면마다 짚는다 |
| 이름 | 가상 이름 현우·유진·수진 | 심사 자료에 실명·계정이 나오면 안 된다. 음성 인식이 한 번에 되는 이름으로 골랐다 |
| 주행 | 구간 1 13.3km(3명) → 하차 → 구간 2 6.3km(2명), 총 1,612원 | 촬영 시간을 줄이려고 짧게 잡았다. 주행은 타임랩스 몇 초로만 쓴다 |

## 3. 장면별 상세

조작은 모두 자동(adb 탭 + Virtual Console 속도·기어 + 주행 재현 도구)으로 한다.

### 0. 오프닝 (8초) — 에뮬레이터 없이 글자만
| 화면 | 자막 |
|---|---|
| 검은 바탕에 한 줄씩 | "기름값, 얼마씩 내면 돼?" → "…아무도 모른다." |
| 앱 이름 | AUTONOMICS — 함께 탄 만큼, 차가 실제로 쓴 만큼. |

### 1. 출발 전 (20초)
| 컷 | 화면과 조작 | 자막 | SDK |
|---|---|---|---|
| 1-1 | 홈 → `정산 모드` 탭 | 출발 전 | — |
| 1-2 | `누가 타나요?` — 마이크 탭 → `듣는 중…` → 이름이 바뀐다 (동승자 2명) | 이름은 말로 넣는다 | SpeechToText (온디바이스) |
| 1-3 | 오른쪽 패널 확대 — `전기차 · 공인 5.0km/kWh`, 충전 단가와 출처 줄 | 차종은 차가, 단가는 자동으로 | Vehicle, 가격 API |
| 1-4 | `출발` 탭 | — | — |

### 2. 주행 중 (22초)
| 컷 | 화면과 조작 | 자막 | SDK |
|---|---|---|---|
| 2-1 | 기어 D, 속도 0→100km/h. 계기판 속도가 오르고 앱 칩이 `정차 중`→`주행 중`, 버튼이 흐려진다 | 달리면 조작이 잠긴다 | 차속 · Gear |
| 2-2 | 타임랩스로 약 30km. 미터기 총액과 세 사람 금액이 함께 오른다 | 배터리가 실제로 줄어든 만큼 오른다 | EvBattery · Odometer |
| 2-3 | 미터기 아래 줄 확대 — `…km · …kWh (실측)` | 추정이 아니라 실측 | — |

### 3. 중간 하차 (25초)
| 컷 | 화면과 조작 | 자막 | SDK |
|---|---|---|---|
| 3-1 | 감속 → 정차. 계기판 0, 칩 `정차 중`, 버튼이 살아난다 | 서면 조작이 열린다 | 차속 · Gear |
| 3-2 | 내리는 사람 칩 탭 → 하차 정산 카드 (`○○ 님 하차 정산`, 금액, 함께 탄 거리, QR) | 내리는 순간, 탄 만큼 확정 | — |
| 3-3 | 폰 화면을 옆에 띄운다 — QR → 정산서 `○○ 님이 낼 금액` → `금액 복사` → `…원 복사했어요` | 동승자는 설치 없이 QR만 | — |
| 3-4 | `확인` → 주행 화면. 내린 사람은 `· 내림`, 금액 고정 | — | — |

### 4. 도착 (25초)
| 컷 | 화면과 조작 | 자막 | SDK |
|---|---|---|---|
| 4-1 | 타임랩스로 약 20km. 내린 사람 금액은 그대로, 남은 두 사람만 오른다 | 이후 구간은 남은 사람끼리 | EvBattery |
| 4-2 | 정차 → `여행 종료` | — | — |
| 4-3 | 정산 완료 — 총액 → 사람별 금액 → 구간별 내역 → `지나온 길` 순서로 강조 | 사람별 금액, 구간, 지나온 길 | 위치 · NaviHelper |
| 4-4 | 이름 탭 → 사람별 정산서 | 사람마다 정산서와 QR | — |
| 4-5 | 화면 위에 비교 카드 | "N빵이면 모두 같은 금액 → 구간 정산이면 먼저 내린 사람은 절반" (촬영한 실제 금액으로) | — |

### 5. 차라서 되는 세 가지 (20초)
| 컷 | 화면과 조작 | 자막 |
|---|---|---|
| 5-1 | 주행 중 금액 → "시동 OFF" → 재부팅 → 앱이 같은 금액에서 이어진다 | 시동을 껐다 켜도 여행은 하나 |
| 5-2 | 정차 → `+ 동승자 추가` → 이름 → `태우기`. 새 사람은 0원부터 | 중간에 탄 사람은 그때부터만 |
| 5-3 | 솔로 모드 `운전 리포트` — 실제 전비, 공인 대비 %, 구간별 막대 | 혼자 탈 때는 운전 효율 리포트 |

## 5. 촬영 전에 고칠 것

| 구분 | 내용 | 이유 |
|---|---|---|
| 꼭 | 충전 단가를 2026년 8월 개편 요금으로 바꾸기 | 출발 화면에 `2022-09-01 시행`이 그대로 찍힌다 |
| 꼭 | Virtual Console의 속도·기어를 자동으로 바꾸는 방법 찾기 | 저장소에 기록이 없다. 못 찾으면 속도만 직접 조작해야 한다 |
| 꼭 | 에뮬레이터에서 음성 입력이 되는지 확인 | 안 되면 이름을 한 번만 직접 말하거나, 글자 입력으로 바꾼다 |
| 권장 | 주행 중에는 `정산 완료 · QR` 버튼 잠그기 | 지금은 주행 중에도 눌린다. 기획서의 "주행 화면에 QR 없음"과 어긋난다 |
| 권장 | 결과 화면에서 운전자 줄은 QR 없이 | 운전자 QR을 찍으면 자기에게 보내라고 나온다 |
| 권장 | 홈의 테스트 기록(0원, 90원 등) 정리 | 홈 화면에 그대로 보인다 |

## 6. 촬영 요령

- 주행 재현 도구는 여행 시작 전에 한 번만 켠다. 중간에 다시 켜면 지도가 강남역으로 튄다.
- 출발 직후와 하차 직후 몇 초는 `(추정)`이 보인다. 그 구간은 쓰지 않는다.
- 시동 OFF/ON 장면은 본편과 다른 짧은 여행으로 따로 찍는다.
- 화면에는 에뮬레이터만 담는다. 바탕화면, 계정 이름, 파일 경로가 보이면 안 된다.
- 폰 장면은 실제 배포된 정산서 페이지를 폰 크기로 열어 찍는다. 주소는 촬영한 QR의 것을 그대로 쓴다.
