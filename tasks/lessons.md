# Lessons

실제로 겪은 실수와, 같은 실수를 막는 규칙. 세션을 시작할 때 읽고, 사용자에게 지적받거나 버그를 고칠 때마다 한 줄 추가한다.
형식: `- [날짜] 무엇을 잘못했나 → 규칙`

- [2026-10-30] 테스트 이름을 백틱 한글로 지었다 → 테스트 포함 모든 식별자는 영어 camelCase. (check_conventions.py가 검사)
- [2026-11-04] 공모전 앱을 가짜 시뮬레이터 데이터로 만들었다 → 차량 값은 처음부터 실제 Pleos SDK로 받는다. 에뮬레이터 입력은 Virtual Console과 tools/emulator_drive.py로 흉내 내고, 앱 코드에 Simulated/Demo/Fake 구현을 두지 않는다. (check_conventions.py가 검사)
- [2026-11-04] 사용자가 직접 테스트할 수 있는 방법을 주지 않고 "됐다"고 했다 → 기능을 넘길 때는 사용자가 에뮬레이터에서 직접 재현할 수 있는 절차(콘솔 항목, 명령)를 함께 준다.
- [2026-11-04] CarPropertyManager·Car.createCar를 메인 스레드에서 동기 호출해 화면이 6초 멈췄다 → 차량 서비스 연결·동기 조회는 Dispatchers.IO에서.
- [2026-11-04] 거리를 주행거리계로만 재서 에뮬레이터에서 엑셀을 밟아도 0km였다 → 주행거리계가 실제로 움직일 때만 쓰고, 멈춰 있으면 차속을 적분한다.
- [2026-11-04] 샘플 시각을 System.currentTimeMillis()로 재서 시계가 튀자 거리·구간이 사라졌다 → 샘플 간격은 SystemClock.elapsedRealtime().
- [2026-11-04] Pleos STT SDK 권한(STT_SERVICE)을 선언하지 않아 설정 화면에서 앱이 죽었다 → 새 SDK를 붙이면 javap/문서로 @RequiresPermission을 확인하고 해당 모듈 매니페스트에 선언한 뒤, 기기에서 그 화면을 실제로 열어 본다.
- [2026-11-04] NaviHelper 위치가 오지 않았는데 원인을 늦게 찾았다 → SDK 호출이 조용히 실패하면 리스너의 onError/onFailed를 로그로 남기고, 먼저 권한(NAVI_ROUTE 등)을 의심한다.
- [2026-11-06] 앱 실행과 부팅 알림이 동시에 여행을 이어 붙여 차량 구독이 겹쳤고, 하나를 정리하면서 Pleos 구독까지 끊겼다 → 재개처럼 여러 곳에서 불리는 진입점은 Mutex로 한 번만 실행되게 한다.
- [2026-11-06] 내비 지명이 앱이 켜진 동안의 모든 여행분으로 쌓여 다음 기록에 섞였다 → 여행 단위로 모으는 상태는 여행을 시작할 때 비운다.
- [2026-11-06] 사용자가 에뮬레이터를 쓰는 중에 내가 탭·강제 종료를 해서 서로의 테스트를 망쳤다 → 사용자가 테스트 중일 수 있으면 화면 조작 전에 상태를 먼저 보고, 겹치면 멈추고 알린다.
- [2026-11-07] 첫 실행 화면을 보려고 `pm clear`로 앱 데이터를 지워 사용자의 테스트 기록까지 날렸다 → 앱 데이터를 지우기 전에 사용자에게 묻거나, 지울 필요 없는 방법(설정 하나만 지우기)을 쓴다.
- [2026-11-10] 충전 요금 기본값이 개편 전 값(347.2원, 2022년 고시)인 채로 "오늘 값"처럼 초록색으로 보였다 → 고시값은 제출·촬영 전에 원문(기후에너지환경부 보도자료)으로 다시 확인하고 시행일을 함께 고친다.
- [2026-11-10] 주행 중에도 `정산 완료 · QR` 버튼이 눌리고 정산 카드가 열린 채 출발할 수 있었다 → 주행 화면에 두면 안 되는 것(입력·QR)은 버튼마다 `state.isStopped`로 막고, 띄워 둔 카드도 출발하면 닫는다.
- [2026-11-13] 시연 촬영 스크립트에 세션 임시 폴더와 홈 절대 경로를 박아 두어, 다른 곳에서 못 돌리고 계정 이름이 저장소에 남을 뻔했다 → 저장소에 넣는 스크립트는 파일 위치 기준 상대 경로만 쓴다. 커밋 전 `git grep -n "/Users/"`로 확인한다.
- [2026-11-13] `tools/__pycache__/*.pyc`가 추적되고 있었고 그 안에 홈 절대 경로가 들어 있었다 → `__pycache__/`, `*.pyc`, 서명 키, `.env`는 처음부터 `.gitignore`에 둔다. 공개 전에는 현재 파일뿐 아니라 git 기록 전체와 커밋 이메일까지 본다.
